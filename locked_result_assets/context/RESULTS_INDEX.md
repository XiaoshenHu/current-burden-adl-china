# Results Index

## Purpose

This public-release index points to the main locked result assets retained in the lean GitHub package. It is intentionally shorter than the internal master-package index and focuses on files that support the manuscript's central claims.

## Core CHARLS result assets

- `sample_flow_locked.csv`: locked main CHARLS sample chain
- `phenotype_profile_locked.csv`: retained phenotype profiles across waves 1-3
- `current_association_results_locked.csv`: locked primary association results
- `emerging_beyond_burden_models.csv`: phenotype beyond-current-burden comparisons
- `adjusted_absolute_risk_by_phenotype.csv`: burden-adjusted absolute risks by phenotype
- `nested_validation_performance.csv`: nested validation performance summary
- `nested_vs_original_comparison.csv`: comparison of original versus strict nested validation
- `m1_calibration_metrics.csv`: calibration summary for the current-burden model
- `m1_observed_vs_predicted_deciles.csv`: decile-level observed versus predicted calibration support
- `risk_stratification_quintiles.csv`: quintile-based risk stratification support
- `risk_stratification_deciles.csv`: decile-based risk stratification support

## Core pragmatic-rule assets

- `r4_operational_high_risk_profile.csv`: operational high-risk profile summary
- `r5_internal_validation.csv`: internal validation summary for the pragmatic rule
- `r6_pragmatic_rule_summary.md`: integrated Stage R summary and manuscript positioning for the pragmatic rule

## Core KLoSA external applicability assets

- `klosa_validation_cohort_definition.md`: KLoSA landmark cohort definition
- `klosa_sample_flow.csv`: KLoSA validation sample flow
- `klosa_M1_performance.csv`: performance of the structural current-burden replication in KLoSA
- `klosa_M1_calibration.csv`: KLoSA calibration summary for the structural current-burden framework
- `klosa_M1_risk_stratification.csv`: KLoSA risk stratification summary
- `klosa_PTS6_performance.csv`: adapted external validation performance of `PTS_6_core`
- `klosa_PTS6_group_characteristics.csv`: high-risk and low-risk group characteristics in KLoSA
- `klosa_external_validation_summary.md`: integrated KLoSA external applicability conclusion

## Context notes retained in public release

- `reanalysis_summary.md`: integrated scientific summary of the locked CHARLS reanalysis
- `revised_study_positioning.md`: concise statement of the most defensible manuscript positioning
- `LIMITATIONS_OF_REANALYSIS.md`: public-release English limitation note aligned to the locked conclusions
