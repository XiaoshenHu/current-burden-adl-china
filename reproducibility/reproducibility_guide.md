# Reproducibility Guide

This release package is designed to support code and result reproducibility without redistributing participant-level survey data.

## Included

- Analytic code
- Data-processing scripts
- A curated subset of locked aggregated result assets supporting the main manuscript claims

## Excluded

- Participant-level CHARLS data
- Participant-level KLoSA data
- Participant-level Gateway Harmonized KLoSA data
- Working manuscript files and manuscript-supporting folders
- Figure and table source-data CSV files
- KLoSA build logs and other non-essential provenance files
- Superseded deliverables and obsolete manuscript drafts

## Practical implication

This public release package supports code inspection and locked-result traceability. Full figure/table rebuilds still require either local access to the internal master package or regeneration of the aggregated result files from the underlying restricted data.
